## Deploy on Cloudflare Pages
1. Cloudflare dashboard → Workers & Pages → Create → Pages → Connect to Git.
2. Select `usernamestack/Annastacia-Enrico-Wedding`.
3. Production branch: `main`.
4. Framework preset: `None`. No build command. Output directory: `/` (repository root).
5. Deploy and open the assigned `*.pages.dev` URL.

The website uses plain HTML, CSS and JavaScript, with no build dependencies. No QR code, seating plan, RSVP backend or photo-upload service is included.
